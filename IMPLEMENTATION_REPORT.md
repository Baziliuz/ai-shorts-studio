# Отчёт о реализации — 15.11.2026

## Что сделано

Создан новый локальный Git-проект AI Shorts Studio. Реализовано настольное приложение PySide6 с русским тёмным интерфейсом: импорт, метаданные ffprobe, встроенный Qt-плеер, клипы/границы в микросекундах, undo/redo, SQLite и настройки JSON, выбор прямоугольников мышью и числовыми полями, четыре режима компоновки, смешивание выбранных аудиодорожек с независимыми уровнями, короткий рендер реального предпросмотра, последовательный экспорт, отмена, прокси, проверка места и безопасная очистка кэша. Источник не меняется.

Экспорт через общий граф FFmpeg: H.264/AAC MP4, четыре разрешения, yuv420p, проверка NVENC реальным кодированием, явный выбор программного кодировщика. Готовые файлы не перезаписываются; промежуточный результат проверяется ffprobe. Задачи и восстановление состояний сохраняются в SQLite; повтор готовых задач автоматически не запускается.

Подготовлены фиксированные зависимости, PyInstaller onedir spec, установщик Inno Setup с ярлыками и сохранением пользовательских данных, Windows CI с тестами/проверкой комплекта Qt/базовым запуском/артефактом установщика. Проверен скачанный архив Windows FFmpeg 7.1.1 и его извлечение по SHA-256. Позже Windows-бинарники FFmpeg также прошли интеграционные тесты на Windows Server 2022 в GitHub Actions.

## Обновление 0.2.0 — экспериментальный полуавтоматический анализ и звук

Реализованы faster-whisper 1.1.1 / CTranslate2 4.6.0, multilingual small, CPU int8; отдельный управляемый процесс; явная установка модели ~464 МиБ с проверкой закреплённых SHA-256 и возобновлением загрузки. После установки анализ работает офлайн. Обработка блоками по 5 минут с перекрытием 5 секунд, кэш по исходнику/дорожке/языку/версии, восстановление готовых блоков и отмена дерева процессов. Кадрирование и параметры будущих клипов не входят в ключ распознавания.

Ранжирование отделено от ASR и использует только эвристики: слова-сигналы в реальном тексте, RMS и разницу уменьшенных кадров (1 кадр/сек.). Строгие границы длительности, удаление пересечений, предел количества без заполнения слабыми вариантами. Названия — фрагменты фактического транскрипта, ссылки только на реальные сегменты. Просмотр исходных кандидатов, ручное принятие/отклонение, создание обычных редактируемых клипов; решения сохраняются локально без автоматического обучения. Смысловой LLM/Ollama, CUDA, распознавание конкретных игровых событий и оценка качества на репрезентативных стримах остаются следующими задачами. Полная приёмка этапа 2 не заявляется.

Звук: включаемая однопроходная loudnorm (ориентир -16 LUFS, -1.5 dBTP), ограничение пиков; sidechain-приглушение остальных выбранных дорожек от отдельного выбранного микрофона. Не разделяет готовый общий микс. Тот же граф используется в предпросмотре и экспорте; тест измеряет снижение уровня игры при голосе.

## 0.3.0 — автоматическая нарезка и обложки

«Создать нарезку» запускает локальный анализ и последовательный экспорт комплектов MP4 и JPG выбранной ориентации. Режим просмотра кандидатов и ручной монтаж используют те же клипы, рендер и обложки. Границы зависят от реплик, тематических переходов и плотности сигналов. Ограничено количество автоматически экспортируемых предложений, длительность клипов определяется содержанием. Покадровое распознавание игровых событий в этой сборке отсутствует.

Экспорт читает оригинал. NVENC проверяется пробным кодированием, при недоступности выбран программный libx264. FFprobe проверяет размер кадра, FPS, длительность и кодеки. MP4 и JPG подтверждаются в SQLite одной транзакцией. Предыдущий комплект сохраняется при отмене, ошибке обложки и перезапуске. Замена кадра или текста создаёт новую версию комплекта с тем же MP4. Старые проекты мигрируют с резервной копией.
