# Отчёт о реализации — 15.11.2026

## Что сделано

Создан новый локальный Git-проект AI Shorts Studio. Реализовано настольное приложение PySide6 с русским тёмным интерфейсом: импорт, метаданные ffprobe, встроенный Qt-плеер, клипы/границы в микросекундах, undo/redo, SQLite и настройки JSON, выбор прямоугольников мышью и числовыми полями, четыре режима компоновки, смешивание выбранных аудиодорожек с независимыми уровнями, короткий рендер реального предпросмотра, последовательный экспорт, отмена, прокси, проверка места и безопасная очистка кэша. Источник не меняется.

Экспорт через общий граф FFmpeg: H.264/AAC MP4, четыре разрешения, yuv420p, проверка NVENC реальным кодированием, явный выбор программного кодировщика. Готовые файлы не перезаписываются; промежуточный результат проверяется ffprobe. Задачи и восстановление состояний сохраняются в SQLite; повтор готовых задач автоматически не запускается.

Подготовлены фиксированные зависимости, PyInstaller onedir spec, установщик Inno Setup с ярлыками и сохранением пользовательских данных, Windows CI с тестами/проверкой комплекта Qt/базовым запуском/артефактом установщика. Проверен скачанный архив Windows FFmpeg 7.1.1 и его извлечение по SHA-256. Это проверка архива, не запуск Windows-бинарников.

## Фактические проверки

Среда: Linux, Python 3.12.14, PySide6 6.8.3, FFmpeg 7.1.5 Debian.

- `python -m pytest -q`: **23 passed in 15.02s**.
- `python -m compileall -q src scripts tests`: успешно.
- `python -m pip check`: No broken requirements found.
- `QT_QPA_PLATFORM=offscreen python -m ai_shorts_studio --smoke-test` с XDG-каталогами в рабочей папке: успешный базовый запуск/выход.
- Визуально просмотрен снимок настоящего Qt-окна в offscreen-режиме; это не проверка декодирования и звука на Windows.

Тесты проверяют границы и нормализованные области, хранение трёх клипов, восстановление задач, историю изменений, импорт нескольких аудиопотоков, повреждённый/отсутствующий источник, четыре композиции, файл без звука, VFR, SAR, прокси, существующий выходной файл, отмену до старта и после начала обработки, фильтры/кодировщики, переход цветового маркера с ошибкой ≤ одного кадра и аудиомаркер с ошибкой <100 мс. GUI-тест проверяет редактирование/отмену/сохранение и преобразование координат области.

## Что ещё не подтверждено

Весь этап 1 **не объявляется принятым**. Windows CI не запускался; Windows-инсталлятор не собран и не установлен; реальные записи, Qt-воспроизведение и RTX 4060 не проверены. RAM/VRAM и скорость на целевом ПК не измерены. Полный список — tests/MANUAL_WINDOWS.md. Лицензионная комплектация бинарного публичного выпуска требует дополнительной проверки, описанной в THIRD_PARTY_NOTICES.md.

Исходный плеер воспроизводит одну выбранную дорожку, а точный многодорожечный микс и его громкости — через рендер предпросмотра. Прокси содержит первую аудиодорожку. Это явно объяснено пользователю; экспорт всегда использует выбранные дорожки оригинала. Предпросмотр ограничен первыми 8 секундами выбранного фрагмента; финальный экспорт обрабатывает весь клип.

## GitHub

Попытка `gh repo create ai-shorts-studio --private --source=.` отклонена GitHub: `GraphQL: Resource not accessible by integration (createRepository)`. Авторизация для аккаунта Baziliuz есть, права создания репозитория нет. Удалённый репозиторий, push, PR и Windows CI не созданы/не выполнены. Это ограничение GitHub-подключения, а не отказ автоматической проверки разрешений.

После создания пустого приватного репозитория пользователем можно подключить remote, загрузить ветки `main` и `codex/stage-1`, открыть PR без автоматического слияния и запустить Windows workflow. Локальный Git сохраняет отдельную начальную ветку и реализацию.
