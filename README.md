# AI Shorts Studio

Локальное настольное приложение с русским интерфейсом для Windows 10/11 x64. Автоматическая нарезка, проверка предложенных моментов и ручной монтаж используют один редактор. Результат — MP4 и отдельная JPG-обложка на каждый экспортированный клип. Видео, звук и проекты обрабатываются локально. Whisper small скачивается один раз по подтверждению.

## Пользователю

В последней успешной [сборке ветки codex/stage-1](https://github.com/Baziliuz/ai-shorts-studio/actions/workflows/windows.yml?query=branch%3Acodex%2Fstage-1) скачайте артефакт `AIShortsStudio-0.3.0-windows-x64`, распакуйте и запустите `AIShortsStudio-0.3.0-win64-setup.exe`. Установка в пользовательский каталог создаёт ярлыки в меню и на рабочем столе. Python и Git устанавливать не требуется. Удаление приложения сохраняет пользовательские проекты.

### Создать нарезку

1. Импортируйте запись и сохраните проект. Нажмите «Создать нарезку», выберите 9:16 или 16:9 и запустите обработку. Можно выбрать игровой стрим или разговорную запись, а также дорожку речи и язык.
2. При первом запуске Whisper можно скачать и сразу начать анализ. При отсутствии модели или сбое распознавания доступен явный переход на отбор по громкости и движению. Клип может включать подводку и реакцию либо законченную реплику. Длина определяется сигналами записи; слабые и пересекающиеся предложения отбрасываются.
3. Приложение создаёт редактируемые клипы и последовательно сохраняет комплекты MP4 + JPG в папке «Название проекта — Нарезка» рядом с проектом. Обложка использует кадр готового видео и короткую фразу из транскрипта, если подходящая фраза найдена. В редакторе можно изменить границы, а через «Редактировать обложку» заменить кадр или текст.
4. Для предварительного просмотра используйте «Найти моменты» и «Предложения моментов». Ручной режим доступен через «Новый клип» или «Нарезать по таймкодам». Кнопка «Оценить момент» сохраняет отдельную пользовательскую оценку пригодности и комментарий в проекте.

### Ручной монтаж

1. «Импорт видео» → файл → имя нового SQLite-проекта. Во время импорта читаются метаданные и вычисляется SHA-256 всего файла; большие записи требуют времени, память ограничена блоком чтения. Расширение не заменяет проверку ffprobe.
2. «Новый клип», название и границы в формате ЧЧ:ММ:СС, например `01:25:30`. Необязательные доли секунды: `01:25:30.500000`. Внутри хранятся целые микросекунды. «Начало здесь» / «Конец здесь» переносят позицию плеера в поля. «Применить изменения» сохраняет законченное действие; Ctrl+Z / Ctrl+Y отменяют/повторяют его.
3. Выберите 9:16 или 16:9, размер и частоту. Повышение fps запрещено. Доступны центральное и ручное кадрирование, размытый фон и шаблон «игра + камера».
4. Области задаются числами X, Y, ширина, высота от 0 до 1 относительно отображаемого исходного кадра (после учёта поворота и SAR). Можно выделить эти области мышью на кадре через соответствующую кнопку. Автоматического обнаружения камеры нет. Для игры выберите прямоугольник без встроенной камеры, когда это возможно. Закрытую часть изображения восстановить нельзя.
5. Отметьте дорожки и их коэффициенты громкости (1 = 100%). По умолчанию включена только первая дорожка, чтобы не дублировать готовый микс. В исходном плеере слышна первая выбранная дорожка; точный многодорожечный микс с громкостями слушайте через «Прослушать выбранный микс». Источники с уже сведённым звуком не разделяются.
6. «Предпросмотр» рендерит до 8 секунд текущего клипа тем же графом, что и экспорт. Это воспроизводимая итоговая компоновка; оригинальный плеер не выдаётся за итоговый рендер.
7. Выберите клипы с Ctrl/Shift → экспорт → папку. Очередь последовательная, вывод — MP4/H.264/yuv420p и AAC при наличии выбранного звука. По умолчанию проверяется NVENC коротким кодированием. Если он недоступен, используется программный libx264, который также можно выбрать вручную.

Проекты автоматически сохраняются после завершённых действий. Последний проект предлагается при следующем запуске. Перенесённый исходник можно указать заново, соответствие проверяется по SHA-256. Изменённый исходник отклоняется. Повторный экспорт может идти в ту же папку. Каждая готовая версия получает свой каталог. После проверки MP4 и сохранения JPG SQLite подтверждает комплект одной транзакцией. При сбое или отмене прежний готовый экспорт остаётся доступным.

Прокси создаётся по явной команде, с исходным соотношением сторон и первой аудиодорожкой. Временные метки остаются относительно оригинала; экспорт и итоговый предпросмотр всегда читают оригинал. В прокси доступна только первая исходная дорожка; проверяйте многодорожечный звук по рендеру. Кэш можно посмотреть и очистить кнопкой «Кэш». Свободное место проверяется с резервом, это не гарантия точного размера будущего MP4.

Каталоги Windows: `%LOCALAPPDATA%\AI Shorts Studio` (настройки, проекты по умолчанию и кэш в подпапке Cache), логи в каталоге log, выбранные пользователем SQLite-проекты — по указанному пути. Фактический путь кэша показан в интерфейсе. Не редактируйте SQLite во время работы приложения.

## Попробовать автоматический поиск и звук

1. Откройте исходник. Нажмите «Найти моменты». При первом запуске подтвердите загрузку многоязычной модели small (~464 МиБ) из Hugging Face/Systran. Версия и SHA-256 закреплены в `assets/models.json`; прогресс — по загруженным байтам. Незавершённую загрузку можно продолжить повторным нажатием. Для проверки/восстановления модели есть «Модель речи». Модель хранится в пользовательском каталоге данных отдельно от кэша и установщика.
2. Выберите «Найти моменты» для просмотра перед экспортом. Укажите дорожку речи (лучше отдельный микрофон), язык и тип записи. Длительность определяется при анализе, а границы можно исправить в редакторе. Whisper работает офлайн в отдельном процессе на CPU int8. Этот процесс завершает работу перед запуском экспорта.
3. Откройте «Предложения моментов». Для каждого видны границы, эвристический балл 0–100, подтверждённые сигналы и выдержка распознанного текста. Можно смотреть исходный фрагмент, отклонить предложение или отметить галочкой для создания клипа. По умолчанию ничего не принято. Уже принятые предложения повторно не создаются.
4. «Создать отмеченные клипы» → поправьте границы/компоновку при необходимости → проверьте итоговый рендер → экспортируйте. Видеофайл не выгружается ни в какой внешний AI-сервис.
5. Для звука отметьте «Выровнять громкость» — динамическая нормализация FFmpeg (ориентир −16 LUFS, true peak −1.5 dBTP). Это однопроходная обработка, а не гарантированная точная двухпроходная LUFS-мастеризация. Пиковый ограничитель используется и без этой настройки.
6. Если микрофон и игра записаны отдельно, выберите обе дорожки, включите «Приглушать игру во время речи» и укажите дорожку микрофона. Остальные выбранные дорожки приглушаются по уровню сигнала микрофона. Громкие посторонние звуки микрофона тоже могут сработать. Если есть готовый общий микс, не добавляйте дублирующие дорожки к нему. Из сведённой записи голос и игру эта функция не разделяет. Прослушивайте результат через рендер предпросмотра, он совпадает с экспортом.

Распознавание и ранжирование разделены: Whisper даёт текст/время, отдельный модуль предлагает фрагменты по словам-сигналам, всплескам RMS и разнице уменьшенных кадров (1 кадр/сек.). Это не смысловая LLM-оценка, не распознавание эмоций/побед/смеха и не прогноз популярности. Ollama и семантическое ранжирование ещё не подключены. Программа может предложить мало клипов или ни одного; количество — верхний предел. Баллы сравнивают эвристики и не являются вероятностями.

Анализ разбит на 5-минутные блоки с перекрытием 5 секунд. Готовые блоки кэшируются по SHA-256 исходника, дорожке, языку, версии модели и пайплайна. Изменение кадрирования не запускает распознавание повторно. Отмена завершает дерево дочерних процессов, готовые блоки пригодны для повторного запуска. Кэш содержит текст речи локально и удаляется через «Кэш» по подтверждению. Перед обновлением схемы проектов до версии 4 создаётся резервная копия `*.vN-backup.sqlite`, где N — версия прежней схемы. Предложения, текущие версии экспортов и пользовательские оценки хранятся в SQLite-проекте.

## Автонарезка по началам

Откройте видео → «Нарезать по таймкодам». Вставьте начала, каждое на новой строке:

```text
05:20 Первый раунд
12:10
01:25:40 Финал
```

Укажите длительность, например 30 секунд, и нажмите «Создать клипы». Конец каждого клипа вычисляется автоматически и ограничивается концом исходника. Новые клипы наследуют компоновку и звук текущего клипа, автоматически выделяются для общего экспорта и сохраняются в проект. Ctrl+Z отменяет создание всей группы. Это нарезка по вашим отметкам; экспериментальный поиск без таймкодов доступен отдельно через «Найти моменты».

## Разработчику

Целевая сборка: CPython 3.12.9 x64, PySide6/Qt 6.8.3, PyInstaller 6.12.0. В Linux проверено на Python 3.12.14 и FFmpeg 7.1.5; Windows CI проверен на Python 3.12.9; пакет использует FFmpeg 7.1.1 Gyan Essentials с проверкой SHA-256, установщик собран Inno Setup 6.7.1. Зависимости зафиксированы в `requirements-dev.lock`. Лицензии и источники — `THIRD_PARTY_NOTICES.md`.

```sh
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux: source .venv/bin/activate
python -m pip install -r requirements-dev.lock -r requirements-ai.lock -e ".[dev,analysis]"
python -m ai_shorts_studio
python -m pytest -q
```

Для разработки нужен FFmpeg/ffprobe в PATH. На Windows:

```powershell
python scripts/fetch_ffmpeg.py
$env:PATH = "$PWD\vendor\ffmpeg\bin;$env:PATH"
python -m pytest -q
python -m PyInstaller --noconfirm packaging/studio.spec
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" packaging/installer.iss
```

Inno Setup 6 устанавливается только на машине сборки. GitHub Actions на Windows Server 2022 выполняет тесты, проверяет Qt Multimedia и собирает установщик. На отдельном Windows Server 2022 runner скачивается готовый пакет, выполняется установка с кириллицей в пути, проверяются запуск из установленной папки и комплектные FFmpeg/ffprobe. Установка и воспроизведение на чистой Windows 10/11 без Python и NVENC на RTX 4060 проверяются отдельно. Сборка не подписана сертификатом.

Структура: `domain` — модель монтажа/история; `storage` — транзакции SQLite; `media` — метаданные, граф композиции, управляемый FFmpeg; `jobs` — фоновые задачи; `ui` — PySide6; `ai` — закреплённая модель, отдельный процесс распознавания, блочный кэш и независимое ранжирование. SQLite — единственный источник проекта, JSON — общие настройки и восстанавливаемый кэш анализа; состояние проекта хранится в SQLite. FFmpeg запускается списком аргументов без shell. Промежуточный MP4 проверяется ffprobe и публикуется атомарно без перезаписи; отмена удаляет только собственный промежуточный файл.

## Проверка и ограничения

Автотесты используют маленькие синтетические файлы, включая кириллицу в путях, VFR, несколько аудиодорожек, отсутствие звука, повреждённый/потерянный файл, таймкоды, сохранение трёх клипов, undo/redo, композиции и программный экспорт. Цветовая граница проверяется с точностью одного кадра, аудиомаркер — до 100 мс. NVENC может отсутствовать — это нормальный результат capability probe.

Не проверены: Windows-инсталляция и деинсталляция, действительное воспроизведение Qt на Windows, полнометражные записи, фактическое потребление RAM/VRAM на целевом ПК. Ручная матрица — `tests/MANUAL_WINDOWS.md`. Таймер оставшегося времени и обещания скорости отсутствуют. Финальная приёмка этапа 1 требует выполнения ручной матрицы и исправления обнаруженных проблем.
